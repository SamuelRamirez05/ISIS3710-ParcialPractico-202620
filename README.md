#Revisión de Accesibilidad y Usabilidad

## Problemas de accesibilidad identificados con Lighthouse

Se realizó una revisión de accesibilidad utilizando Lighthouse en la página de exploración de planes (`/plans`). Se identificaron los siguientes problemas:

1. Los botones no tienen un nombre accesible.
2. Las imágenes no tienen el atributo `alt`.
3. El documento no tiene un elemento `<main>` que identifique el contenido principal.
4. El elemento `<html>` no tiene definido el atributo `lang`.
5. Los encabezados no siguen un orden jerárquico secuencial.

Para los errores use Lighthouse en la pagina prncipal y en la explorar planes
